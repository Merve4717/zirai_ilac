# 🌱 Zirai İlaç ERP Sistemi

ASP.NET Core MVC, Entity Framework Core ve SQL Server kullanılarak geliştirilmiş bir Zirai İlaç ERP (Enterprise Resource Planning) uygulamasıdır.

Bu proje, tarım sektöründe faaliyet gösteren işletmelerin ürün ve stok yönetim süreçlerini dijital ortamda takip edebilmesi amacıyla geliştirilmiştir.

---

## 📋 Proje Özeti

Zirai İlaç ERP Sistemi, ürünlerin kayıt altına alınmasını, stok bilgilerinin takip edilmesini ve temel ürün yönetimi işlemlerinin gerçekleştirilmesini sağlayan web tabanlı bir uygulamadır.

Proje kapsamında modern yazılım geliştirme yaklaşımları kullanılarak katmanlı yapı, veritabanı yönetimi ve kullanıcı arayüzü geliştirme süreçleri uygulanmıştır.

---
